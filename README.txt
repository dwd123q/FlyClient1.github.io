FLY CLIENT WEBSITE

1. Требования: PHP 8.1+ с PDO_SQLite и SQLite3.
2. Загрузите ВСЕ содержимое этой папки в public_html (или аналогичный web-root).
3. Откройте сайт. База data/fly.sqlite создастся автоматически.
4. Первые администраторы:
   FlyOwner / FlyOwner-ChangeMe!2026
   FlyDev   / FlyDev-ChangeMe!2026
   СРАЗУ после входа смените эти пароли через базу/добавленный password reset механизм.
5. Клиент уже лежит в downloads/fly-client-1.0.2.jar и выдаётся только пользователю с активной подпиской или админу.

ВАЖНО: Перед публичным запуском настройте HTTPS, резервное копирование SQLite и смените начальные пароли администраторов.

Цены в коде: 30 дней 200 RUB, 180 дней 400 RUB, 365 дней 500 RUB, lifetime 700 RUB.
Валюта: RUB/EUR/USD/GBP с фиксированными коэффициентами. Для реальных актуальных курсов подключите серверный FX API.
